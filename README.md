# verilog-exam-labs

Exam labs that students pull with **Sync Lab Templates > Sync Single Lab** in the Classroom 50 panel.
Each lab is a folder `labs/<name>/task1..task3` (names must start with `lab`).

- `labs/lab-practice`: push before the practice session.
- `labs/lab-slot1`, `labs/lab-slot2`, `labs/lab-slot3`, `labs/lab-makeup`: push each one only when
  its slot starts. Anything pushed here can be synced (and read on GitHub) by every student.
